# Publicar NEXORA en GitHub Pages

1. Crea un repositorio público, por ejemplo `nexora-lovable`.
2. Sube todo el contenido de esta carpeta, incluido `.github`.
3. En el repositorio, abre **Settings → Pages** y selecciona **GitHub Actions** como origen.
4. Abre **Actions** y espera a que termine `Deploy NEXORA to GitHub Pages`.
5. En **Settings → Pages** aparecerá el enlace público.

El proyecto usa el código exportado de Lovable y sus imágenes locales. No necesitas conectar Lovable con GitHub ni contratar esa integración.
